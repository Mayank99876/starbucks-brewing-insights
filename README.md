## 📌 Project Overview

**Starbucks Brewing Insights** is an interactive Power BI dashboard designed to explore Starbucks beverage data and uncover insights into beverage categories, calorie content, caffeine levels, and nutritional composition.

The project demonstrates how data analytics and visualization can transform raw beverage data into meaningful insights, helping users compare products and understand nutritional patterns across different beverage categories.

## 🎯 Project Objectives

- Analyze the distribution of Starbucks beverages across categories.
- Compare calorie content across different beverage types.
- Explore caffeine content and identify differences between beverages.
- Examine nutritional characteristics to understand beverage composition.
- Develop an interactive dashboard for quick and effective data exploration.

## 🛠️ Tools & Technologies

- **Microsoft Power BI:** Dashboard development and data visualization
- **Power Query:** Data cleaning and transformation
- **DAX:** Measures and calculated metrics, where applicable
- **Data Visualization:** KPI cards, bar charts, donut charts, and trend charts
- **Data Analysis:** Category-wise comparison and nutritional analysis

## 📊 Dashboard Features

### 1. Beverage Category Analysis
Explore the distribution of beverages across categories and understand the composition of the available menu.

### 2. Calorie Analysis
Compare calorie values across beverage categories to identify differences in nutritional content.

### 3. Caffeine Content Analysis
Analyze caffeine levels across beverages to understand how caffeine content varies by beverage type.

### 4. Nutritional Comparison
Explore available nutritional attributes and compare beverage characteristics using interactive visualizations.

### 5. Interactive Filtering
Use available filters and slicers to explore the dataset based on selected nutritional attributes or beverage categories.

## 💡 Key Business Questions

- Which beverage categories contain the most menu items?
- How does calorie content vary across beverage categories?
- Which beverages have comparatively higher caffeine content?
- How do nutritional characteristics differ between categories?
- How can interactive dashboards make product comparisons easier?
